# AI-Based Network Intrusion Detection System

## Overview

This project presents an AI-Based Intrusion Detection System (IDS) designed to classify network traffic as either normal or malicious. The system was developed using Machine Learning and Deep Learning techniques and evaluated using the NSL-KDD dataset.

## Objectives

* Detect malicious network activities.
* Compare the performance of different AI models.
* Evaluate the effectiveness of Machine Learning and Deep Learning approaches in intrusion detection.

## Dataset

**NSL-KDD Dataset**

The NSL-KDD dataset was used for training and testing the models. It contains network traffic records labeled as either normal or attack traffic.

## Data Preprocessing

The following preprocessing steps were applied:

* Feature encoding
* Normalization
* Sparse feature removal
* Training and testing data preparation

## Implemented Models

### 1. Logistic Regression

Used as the baseline model for binary classification.

### 2. Random Forest

Implemented as an improved Machine Learning model using ensemble learning techniques.

### 3. Neural Network

A Feedforward Neural Network was implemented to explore the effectiveness of Deep Learning in intrusion detection.

## Evaluation Metrics

The models were evaluated using:

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix
